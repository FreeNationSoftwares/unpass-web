# Unpass — Free Online PDF & Photo Tools

Unlock, merge, split, compress and convert PDFs, plus photo/signature resizing for exam & govt forms. Everything runs **100% in the browser** — no file is ever uploaded.

Live site: hosted on GitHub Pages. Built by FreeNation Softwares.

## Tech
- Static HTML/CSS/JS, no build step.
- [pdf-lib](https://github.com/Hopding/pdf-lib) (MIT) for building/merging/splitting PDFs.
- [pdf.js](https://github.com/mozilla/pdf.js) (Apache-2.0) for opening, decrypting and rasterizing PDFs.
- [JSZip](https://github.com/Stuk/jszip) (MIT) for ZIP downloads.

Licenses for bundled libraries are in `assets/lib/`.
