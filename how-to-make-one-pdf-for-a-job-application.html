How to Make One PDF for a Job Application

By FreeNation Softwares · Updated 2026-11-12

Open the Merge PDF tool →

Many job portals accept only one file, and recruiters prefer a single, tidy PDF to five separate attachments. Here is how to put your whole application together in a few minutes.

Step by step

  1. Turn everything into PDFs — Export your CV as PDF; photograph certificates and convert them with Image to PDF.
  2. Open Merge PDF — Select all the PDFs.
  3. Put them in order — Cover letter, CV, then certificates — newest first.
  4. Merge — Download the single combined PDF.
  5. Check the size — Compress it if it is over the portal's limit.
💡 Name the final file professionally, for example Firstname_Lastname_Application.pdf — it is the first thing a recruiter sees.

A good order for your application

  1. Cover letter (one page)
  2. CV / resume
  3. Degree certificates and transcripts
  4. Experience letters
  5. ID or other documents only if asked

Keeping it under the limit

Most portals allow 2–5 MB. Scanned certificates are the heavy part, so use Compress PDF on the final file if needed.

FAQ

Should the CV be a separate file?

If the portal has separate upload fields, follow them. Otherwise, one combined PDF is easiest for recruiters.

Will merging change my CV's formatting?

No. Merging keeps every page exactly as it was.

Can I remove a page later?

Yes, use Delete PDF Pages.
